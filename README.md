## Run Locally

```bash
# Clone the repository
git clone https://github.com/msn-del/cv.git
cd cv
```

Then either open `index.html` directly in your browser, or serve it locally:

```bash
python3 -m http.server 8000
# or
npx serve
```

Visit `http://localhost:8000`.

## Customize

1. Edit the text in `index.html`
2. Change colors, fonts, and layout in `cv.css`
3. Replace `me.jpg` with your own photo
4. Update the email, phone, GitHub, and map links in the profile section

## Deployment (GitHub Pages)

1. Push the repository to GitHub
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)`
4. The site will be live at `https://msn-del.github.io/<repo-name>`

## Export to PDF

Open the page in Chrome, press `Ctrl/Cmd + P`, choose **Save as PDF**, and enable **Background graphics**.
